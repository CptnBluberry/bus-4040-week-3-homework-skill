# bus-4040-week-3-homework-skill

Week 3 homework, Part 1 — building a Claude Skill.

This repo containsone skill, under `.claude/skills/` called **`anki-flashcards`** 
---

## What the skill does

 `anki-flashcards`, a skill for generating flashcards from
my own Anki collection. It lays out the format for creating flashcards with my preferred flashcard app.  I based it off of an export of my flashcards for Theory of Computation class

## Why I made the skill

  Because I use anki flashcards for all my classes.  I like the way it automatically handles the spaced repitition for me, but they're a bit combersom to make on my own.

## What I actually learned

What a skill is.  In claude's own words "So a skill is essentially: onboarding documentation for a new hire, except the new hire is Claude. You're packaging procedural knowledge — the steps, the house style, the gotchas — that Claude can't infer on its own."


## How this can be useful later

This will make it so much quicker to make flashcards, and it even noticed the quirks of my own flashcard style.  I saw claude noticed the way I usually include an "in plain english" section in my flashcards, and included a note to do that in future cards.  I'm going to use this to study for my other classes.  BTW, Anki can sync across devices, so it's a really good flashcard format.
