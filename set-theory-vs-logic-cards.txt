#deck:Set Theory vs Logic
What does \(x \in A\) mean, and what role does it play in logic?	\(x\) is an element of the set \(A\).<br><br>Or in plain English: "\(x \in A\)" is a <b>statement</b> — for a given \(x\) it is either true or false.<br><br>Logic counterpart: it behaves like an atomic proposition \(P\). Every other set operation is built by hanging a logical connective off statements of this shape.
What is \(A \cup B\), and which logical connective defines it?	<b>Union.</b><br>\[A \cup B = \{x \mid x \in A \lor x \in B\}\]Or in plain English: everything in \(A\), everything in \(B\), thrown together.<br><br>Logic counterpart: <b>OR</b> (\(\lor\)). Membership in the union is the disjunction of the two membership statements.
What is \(A \cap B\), and which logical connective defines it?	<b>Intersection.</b><br>\[A \cap B = \{x \mid x \in A \land x \in B\}\]Or in plain English: only the things in <i>both</i> sets.<br><br>Logic counterpart: <b>AND</b> (\(\land\)).
What is \(A^c\) (also written \(\overline{A}\) or \(A'\)), and which logical connective defines it?	<b>Complement.</b><br>\[A^c = \{x \in U \mid x \notin A\}\]Or in plain English: everything in the universal set \(U\) that is <i>not</i> in \(A\).<br><br>Logic counterpart: <b>NOT</b> (\(\neg\)).<br><br>(Complement is only meaningful once a universe \(U\) is fixed — "not in \(A\)" has to be "not in \(A\), out of what?")
What is \(A \setminus B\) (set difference), and how does it read as a logical formula?	Everything in \(A\) that is not in \(B\).<br>\[A \setminus B = \{x \mid x \in A \land x \notin B\}\]Logic counterpart: <b>AND NOT</b>, i.e. \(P \land \neg Q\).<br><br>(Equivalently \(A \setminus B = A \cap B^c\) — the same way \(P \land \neg Q\) is how you'd write it with the basic connectives.)
What is \(A \triangle B\) (symmetric difference), and which logical connective defines it?	Things in exactly one of the two sets.<br>\[A \triangle B = (A \setminus B) \cup (B \setminus A)\]Logic counterpart: <b>XOR</b> (\(\oplus\)) — exclusive or.<br><br>Or in plain English: "in \(A\) or in \(B\), but not both."
What does \(A \subseteq B\) mean, and which logical connective does it correspond to?	<b>Subset:</b> every element of \(A\) is also in \(B\).<br>\[A \subseteq B \iff \forall x\,(x \in A \Rightarrow x \in B)\]Logic counterpart: <b>implication</b> (\(\Rightarrow\)).<br><br>Or in plain English: "being in \(A\) is enough to guarantee being in \(B\)."
Why is \(\emptyset \subseteq A\) true for every set \(A\)?	Because subset is an implication, and the implication \(x \in \emptyset \Rightarrow x \in A\) is <b>vacuously true</b> — the hypothesis is never satisfied.<br><br>Logic counterpart: \(F \Rightarrow Q\) is true no matter what \(Q\) is. Same rule, same reason.
What does \(A = B\) mean in set theory, and how do you prove it?	Both sets contain exactly the same elements: \(A \subseteq B\) <b>and</b> \(B \subseteq A\).<br><br>Logic counterpart: the <b>biconditional</b> (\(\iff\)). Just as \(P \iff Q\) is proved by showing \(P \Rightarrow Q\) and \(Q \Rightarrow P\), set equality is proved by double inclusion.
What is \(\emptyset\), and what is its logical counterpart?	The <b>empty set</b> — the set with no elements.<br><br>Logic counterpart: a <b>contradiction</b> (always false, \(F\)). The condition "\(x \in \emptyset\)" is false for every \(x\).<br><br>(Note \(\emptyset \neq \{\emptyset\}\): the second is a set containing one thing, so its cardinality is 1, not 0.)
What is the universal set \(U\), and what is its logical counterpart?	The set of everything under discussion in the current problem.<br><br>Logic counterpart: a <b>tautology</b> (always true, \(T\)). The condition "\(x \in U\)" is true for every \(x\) in play.<br><br>(\(A \cup A^c = U\) is the set version of the law of excluded middle, \(P \lor \neg P\).)
State De Morgan's law for the complement of a union, and its logic twin.	\[(A \cup B)^c = A^c \cap B^c\]Logic twin: \(\neg(P \lor Q) \equiv \neg P \land \neg Q\)<br><br>Or in plain English: "not (in A or B)" means "not in A <i>and</i> not in B." Push the complement inward and the \(\cup\) flips to \(\cap\).
State De Morgan's law for the complement of an intersection, and its logic twin.	\[(A \cap B)^c = A^c \cup B^c\]Logic twin: \(\neg(P \land Q) \equiv \neg P \lor \neg Q\)<br><br>Or in plain English: if something fails to be in both, it must be missing from at least one.
What does set-builder notation \(\{x \in U \mid P(x)\}\) mean?	"The set of all \(x\) in \(U\) such that \(P(x)\) is true." The bar \(\mid\) (or a colon) reads as <b>"such that."</b><br><br>Or in plain English: hand it a logical predicate and it hands you back the set of things that make the predicate true.<br><br>This is the bridge between the two subjects: <b>every predicate defines a set, and every set is defined by a predicate.</b>
What is the difference between \(x \in A\) and \(\{x\} \subseteq A\)?	\(x \in A\) says the <b>element</b> \(x\) is in \(A\). \(\{x\} \subseteq A\) says the <b>one-element set</b> containing \(x\) is contained in \(A\).<br><br>Both are true at the same time, but they are different statements: \(\in\) relates an element to a set, \(\subseteq\) relates a set to a set.<br><br>(So \(x \subseteq A\) and \(\{x\} \in A\) are usually type errors — watch for these on exams.)
What is the power set \(\mathcal{P}(A)\), and how large is it?	The set of <b>all subsets</b> of \(A\), including \(\emptyset\) and \(A\) itself.<br><br>If \(|A| = n\), then \(|\mathcal{P}(A)| = 2^n\).<br><br>Or in plain English: building a subset means making one independent yes/no decision per element — same counting as filling in a truth table with \(n\) variables, which also has \(2^n\) rows.
What does \(|A|\) denote?	The <b>cardinality</b> of \(A\) — the number of elements in it.<br><br>\(|\{a, b, c\}| = 3\), \(|\emptyset| = 0\).
What is \(A \times B\), and what are its elements?	The <b>Cartesian product</b>: the set of all ordered pairs with the first entry from \(A\) and the second from \(B\).<br>\[A \times B = \{(a,b) \mid a \in A \land b \in B\}\]\(|A \times B| = |A| \cdot |B|\).<br><br>(Order matters — \((a,b) \neq (b,a)\) — unlike sets, where \(\{a,b\} = \{b,a\}\).)
What does it mean for sets \(A\) and \(B\) to be disjoint?	They share no elements: \(A \cap B = \emptyset\).<br><br>Logic counterpart: \(P \land Q\) is a contradiction — the two conditions can never hold at once, i.e. they are mutually exclusive.
What is the inclusion-exclusion formula for \(|A \cup B|\)?	\[|A \cup B| = |A| + |B| - |A \cap B|\]Or in plain English: add both counts, then subtract the overlap once because you counted it twice.<br><br>(Three sets: add the three singles, subtract the three pairwise intersections, add back the triple intersection.)
What does \(\bigcup_{i=1}^{n} A_i\) mean, and which quantifier does it correspond to?	The union of a whole family of sets: \(x\) is in it if \(x\) belongs to <b>at least one</b> \(A_i\).<br>\[\bigcup_{i=1}^{n} A_i = \{x \mid \exists i\,(x \in A_i)\}\]Logic counterpart: the <b>existential quantifier</b> \(\exists\) — a big OR chained across all \(i\).
What does \(\bigcap_{i=1}^{n} A_i\) mean, and which quantifier does it correspond to?	The intersection of a family of sets: \(x\) is in it only if \(x\) belongs to <b>every</b> \(A_i\).<br>\[\bigcap_{i=1}^{n} A_i = \{x \mid \forall i\,(x \in A_i)\}\]Logic counterpart: the <b>universal quantifier</b> \(\forall\) — a big AND chained across all \(i\).
What is a proper subset, and how is it written?	\(A \subsetneq B\) (some texts write \(A \subset B\)): \(A\) is contained in \(B\) <b>and</b> \(A \neq B\), so \(B\) has at least one element \(A\) lacks.<br><br>Or in plain English: strictly smaller, the way \(3 &lt; 4\) is strict while \(3 \leq 4\) is not.<br><br>(Because \(\subset\) is ambiguous across textbooks, prefer \(\subseteq\) and \(\subsetneq\) when you want to be unmistakable.)
