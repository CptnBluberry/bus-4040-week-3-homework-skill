## Homework Exercises

- Part 1, create a Claude Skill
  - In your personal GitHub account
    - Create a new repo called **bus-4040-week-3-homework-skill**
    - Make it **Public**
    - Set **Add README** to **On**
  - Clone the repo to your local computer
  - In Claude, make a skill
    - If you do not know how to create a skill, ask Claude to help you
  - Upload the skill to the repo
  - Use the `README.md` in that folder to explain what learned from the exercise
    - What does the skill do
    - How does the skill work
    - Why did you create the skill
    - How can the skill be useful later

- Part 2 (vibe code "One Shot" prompt) 
  - In your personal GitHub account
    - Create a new repo called **bus-4040-week-3-homework-quiz-sim**
    - Make it **Public**
    - Set **Add README** to **On**
  - Clone the repo to your local computer
  - Use the material from weeks 1 through 3 and have AI build a quiz simulator
  - Example prompt: (adjust the prompt. Make it yours)
    > I'm a business student in an introductory AI course. Build me a quiz simulator so I can test my understanding of the course material.

    >Source material: use ONLY the files in this folder, the weekly narratives for
    
    > weeks 1 through 3 and their associated material. Do not add facts from outside these files. If something in the material is unclear, skip it rather than guessing.

    > What to build: one self-contained index.html file that runs when I double click it. No server, no build step, no internet connection, no external libraries. Put the HTML, CSS, JavaScript, and all the questions in that single file.

    > How the quiz should work:
    > - 20 questions drawn from the material, a mix of multiple choice and true/false
    > - One question at a time, shuffled on each run
    > - Tell me immediately whether I was right, and explain why
    > - Name which week each answer comes from so I know where to review
    > - Show my score at the end, and let me retry just the ones I missed

    > Use plain language. Don't introduce terms the course material doesn't use.
  - Commit your changes, create a PR, and merge the PR
  - Take the quiz
  - Use the `README.md` in that folder to explain what you learned from the exercise
    - What type of quiz did you create
    - What worked
    - What did not work
    - Did you have to make adjusts
    - How could you apply this to other activities
  - Submit the repo URL in Canvas
